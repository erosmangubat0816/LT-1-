# LT-1-

#Description
This codes help us identify the amount of boxes that can be filled when the user gives the amount of notebooks and boxes, and also gives us the amount leftover. 

#How to run
To run the program, you need to open the file in a python-supported coding app like VS Code or Online GDB,

#Variables in code
number_of_notebooks - the amount of notebooks to be given by the user
box_number - the amount of boxes to be given by the user

#Sample Input
What is the total amount of notebooks?
11
How many of them fit inside one box?
2

#Sample Output
the total number of boxes tha can be filled is: 5
the number of leftover notebooks is: 1 left
